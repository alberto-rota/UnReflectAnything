# Image Assets for GitHub Pages

## Slider Images

For the image transition sliders to work, you need to add the following image pairs in the `assets/` folder:

- `slider1_before.jpg` and `slider1_after.jpg`
- `slider2_before.jpg` and `slider2_after.jpg`
- `slider3_before.jpg` and `slider3_after.jpg`

Each pair should show a "before" and "after" comparison. The slider will allow users to reveal the "after" image by dragging.

**Recommended image dimensions:** 16:9 aspect ratio (e.g., 1920x1080 or 1280x720)

## Button Icons

SVG icons for buttons are located in `assets/icons/`:
- `paper.svg` - Paper button icon
- `source.svg` - Source Code button icon
- `installation.svg` - Installation button icon
- `huggingface.svg` - Huggingface button icon
- `contact.svg` - Contact button icon

You can replace these with your own custom SVG icons. The icons should be 24x24 viewBox and use `currentColor` for the fill/stroke so they inherit the button's text color.
